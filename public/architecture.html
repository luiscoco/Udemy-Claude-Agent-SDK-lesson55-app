The browser starts a real local job process. It prepares a trusted Git fixture, then runs the actual headless CLI or Agent SDK. Native results, scoped changes and independent checks determine a real process exit. The gate is code within the local job, not a separately deployed CI service. Numbered steps group alternative CLI and SDK paths.
