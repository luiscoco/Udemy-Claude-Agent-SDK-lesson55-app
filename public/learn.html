01

Run the real headless CLI

Use the pinned bundled claude binary with -p and JSON output. Compare ordinary project-memory discovery with --bare plus an explicit rules file. Reduced configuration discovery does not make model outputs deterministic.

02

Parse native machine-readable results

Inspect the actual CLI JSON envelope, result subtype, structured_output, cost estimate, stdout, stderr and process exit. Invalid JSON Schema produces a real validator diagnostic before model work.

03

Build an unattended SDK step

Use settingSources: [], explicit tools, dontAsk and finite turn/spend estimates. A known unapproved command is denied by the native permission mode rather than waiting for a human.

04

Fix a trusted lint fixture

The SDK runs a tiny teaching linter, changes only var message to const message and reruns lint and tests. The host verifies the exact source change and independently runs the same trusted checks; this is not a general-purpose ESLint bot.

05

Gate on evidence and actual exit codes

Native model success and CI policy are separate. The worker exits nonzero for a denied tool, incomplete run, schema failure or failed lint gate. The browser observes the actual OS process exit instead of displaying an invented pass badge.

06

Configure GitHub workflows safely

Source checks run without an API key. A manual main-branch agent workflow uses a repository secret when you choose to configure it. A Claude Code Action reference is included separately; no hosted agent run, comment, PR or automatic commit is performed by the classroom app.
